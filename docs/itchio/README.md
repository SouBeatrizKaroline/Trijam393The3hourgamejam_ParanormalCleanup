# itch.io theme artwork

| itch.io field | Upload |
| --- | --- |
| Banner | `banner.png` — title and tagline |
| Background | `background.png` — quiet dark page wallpaper |
| Embed BG | `embed-bg-title.png` — haunted room with the game title |

An optional version without text is provided as `embed-bg.png`.

All images were generated with the built-in image generation tool. These are promotional page illustrations, not screenshots of the gameplay. Keep the project AI generation disclosure set to **Yes**. Full prompts are in [PROMPTS.md](PROMPTS.md).
